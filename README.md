# AWS s3 static website hosting

This project demonstrates how to host a public static website using Amazon S3

## Technologies practiced and used:
  - AWS S3
  - GitHub
  - HTML

## Features of the project
  - Static website hosting
  - Public access using bucket policy
 
## Live Demo
http://mystaticwebsite1.s3-website-us-east-1.amazonaws.com

## What I Learned
- Creating and configuring S3 buckets
- Managing public access permissions
- Hosting static websites in AWS using S3
- Cloud cost awareness

## Security Note
Public access was enabled for learning purposes. On large-scale projects using http and CloudFront is preferable and suggested as well.

## Cleanup
AWS resources were deleted after testing to avoid unnecessary charges.
